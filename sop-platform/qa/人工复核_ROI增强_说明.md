# PCB 0264/0265 ROI 增强预标注人工复核说明

生成日期：2026-08-20

## 数据性质

本目录中的框由 YOLOE 开放词汇预标注、PCB/物料 ROI 切片增强和 NMS 合并生成，仅作为人工复核候选，不是量产真值。所有模型保持 `HOLD`，直至人工确认并使用冻结测试集重新验收。

## 人工复核重点

1. 检查 PCB 板是否完整框选，不能只框治具或工作台。
2. 分别检查电容物料区、电感物料区和混合物料区，纠正漏框、错类和重复框。
3. 对遮挡、手部进入、取料、对位、插装、按压、复检及工序切换位置逐项复核。
4. 所有 NG、稀有类别、边界帧必须人工确认，不得只依据自动置信度放行。
5. `images/` 与 `labels/` 文件同名；标签格式为标准 YOLO：`class_id x_center y_center width height`，坐标均为 0 到 1。
6. 0264 与 0265 应按完整视频分别保留训练/验证/测试边界，禁止随机拆散相邻帧造成数据泄漏。

## 目录说明

- `datasets/PCB插装0264_YOLOE_ROI增强_待人工复核`：0264 图片、YOLO 标签和数据清单。
- `datasets/PCB插装0265_YOLOE_ROI增强_待人工复核`：0265 图片、YOLO 标签和数据清单。
- `web/data`：逐帧检测候选及视频元数据。
- `web/analysis/pcb_roi_previews`：带 YOLO 框的抽样预览图。
- `web/media/local`：用于网页/CVAT 人工复核的 720p 代理视频。
- `qa`：完整性验证结果及本说明。

## 推荐检查顺序

先查看 `pcb_roi_previews` 确认区域和类别，再在 CVAT 中加载 720p 视频及候选框进行逐关键帧复核。固定目标每 15-30 帧设关键帧，手、工具和运动目标每 3-5 帧设关键帧；在遮挡、方向变化、工序切换和 NG 位置补关键帧。
