# CVAT、三产线数据集与训练验收说明

## CVAT 分工

平台导航的主标注入口已经统一为 CVAT。当前网页保留逐帧预标注浏览和人工复核能力，正式生产标注建议在 CVAT 完成：

- 目标框：PCB 元器件、汽车固定件、螺丝、涂料区域和缺陷；
- Mask：喷涂区域、焊点、划痕/污迹边界；
- Track：手部、工具、胶枪和跨帧零件；
- ROI：每个固定相机先画一个外层工位/步骤区域，ROI 内仍必须标目标框或 Mask，ROI 不能替代目标真值。

本地服务默认地址是 `http://127.0.0.1:8096`，CVAT 默认地址是 `http://127.0.0.1:8081`。正式部署时设置：

```bash
export CVAT_URL=http://<DGX或厂内服务器>:8081
export CVAT_TOKEN=<CVAT个人Token>
```

没有 `CVAT_TOKEN` 时，网页仍能打开 CVAT 任务列表，但不会伪造“任务已由 API 创建”。

## 三条产线统一标签方向

1. PCB 贴片/焊接：PCB 板、电阻、电容、电感、二极管、芯片、连接器、焊点、缺件、错件、手部、烙铁/焊枪。
2. 汽车零部件装配：仪表板总成、骨架、饰板、线束、接插件、电动紧固工具、手部、螺钉头、螺栓头、塑料卡扣、线束插头、紧固孔。
3. 喷涂/胶水：产品表面、划痕、污迹、凹凸不平、喷涂区域、胶枪、胶线、断胶、漏喷、不均匀。

完整来源、链接和许可核验备注见 `config/dataset_catalog.json`。开源仓库和数据集许可证不完全相同，图片进入商业训练集前仍需由项目负责人核验许可、来源和是否允许再分发。

## 一键训练验收边界

网页训练页可以选择 YOLO26N、YOLOE-26S+SAHI、RT-DETRv2、D-FINE、Anomalib，并登记统一流水线：训练、推理、验证、测试、可视化报告。现有 10 张图表用于展示流程和已生成基线证据；不能把预标注一致性或少量速度样本当成量产精度。

正式验收必须满足：人工确认标签、按产品/工单隔离 train/val/frozen test、同一硬件和输入尺寸、报告 mAP50-95、关键缺陷召回率、每百件误报、P95 延迟、显存和连续运行稳定性。验证前不能宣称“训练很多遍后达到最优”。

## 外部 Manus 发布

当前 `https://sop-pcb-ai-g89st3df.manus.space/users` 返回的是已经编译的 React 静态站点，工作区没有对应源码仓库、Manus 项目 API Token 或部署命令。因此本地已完成的 Python 后端和静态前端不能直接写入该远程站点。发布需要在 Manus 项目控制台导入本项目源码/构建产物，并配置后端公网地址、`CVAT_URL`、`CVAT_TOKEN` 和文件存储；不能仅凭一个公开 URL 安全地替换站点。

## DGX Spark 与 Insta360 Link 2C

当前主机已确认是 `spark-3a40`，NVIDIA GB10、ARM64、约 121GiB 系统统一内存。视觉训练、YOLOE/SAHI预标注、验证测试、模型仓库和主要推理放在Spark；工控机保留相机采集、扫码、串口、PLC、MES缓存以及YOLO11n断网降级。

模型仓库默认位于 `/home/xjai/sop-model-store`。已存在的项目模型通过硬链接登记，不重复占用空间，`registry.json` 保存 SHA-256。RT-DETRv2-S 和 D-FINE-N 仅登记官方 COCO 通用预训练权重，是交叉验证和迁移学习起点，不是三产线成品模型。Anomalib 仍需用模塑/焊点现场正常与 NG 数据训练，不能标为已部署。公开权重和数据集投入商业使用前须再核验项目许可证。

Insta360 Link 2C 已绑定稳定路径：

`/dev/v4l/by-id/usb-Insta360_Insta360_Link_2C-video-index0`

`video-index1` 是UVC元数据节点，不是第二路视频。设备公开30种格式/分辨率/FPS组合和13个UVC控制项，MJPEG/H.264的4K、1080P、720P 30FPS模式均通过30帧采集测试。SOP实时识别建议先使用 `MJPEG 1920x1080@30`；4K优先用于离线采集、小元件特写或单路推理。现场固定补光后应锁定曝光、白平衡和对焦，再保存相机参数。

完整能力报告：`qa/insta360_link2c_capabilities.json`。
