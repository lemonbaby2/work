# Windows APP 安装与运行说明

## 1. 适用范围

Windows APP 是平台启动器和局域网客户端。AI 训练、CVAT、摄像头采集和主数据库建议继续运行在 DGX/Linux 主机；Windows 负责启动、打开网页、查看视频、标注和下载交付结果。

## 2. 安装

将 Windows 交付 ZIP 解压到英文或中文均可的固定目录，例如 `D:\soplzp0820_20260820`。不要直接在压缩包中双击 EXE。确认目录中包含 `SOP平台.exe`、平台源码、启动脚本、文档和校验文件。

首次使用先核对 `SHA256SUMS.txt`。Windows Defender 若提示未知发布者，应由公司 IT 核对哈希后放行，不要关闭整机防病毒功能。

## 3. 启动

双击 `SOP平台.exe`。启动器会检查本地组件，并打开平台地址。DGX 部署模式下使用 `http://192.168.1.129:8096`；CVAT 使用 `http://192.168.1.129:8081`。新版启动器还提供“打开 DGX 三路原生监控”，登录后直接显示三路检测帧，不加载完整管理网页。

开发者、管理者和员工使用各自的平台账号。CVAT 账号与 SOP 平台账号相互独立。

## 4. 网络

Windows 与 DGX 必须在可互通的同一局域网。2.4 GHz 与 5 GHz 名称可以不同，但不得启用客户端隔离。可在 Windows PowerShell 执行：

```powershell
Test-NetConnection 192.168.1.129 -Port 8096
Test-NetConnection 192.168.1.129 -Port 8081
```

若测试失败，检查本机 IP、网关、防火墙、VLAN 和 DGX 服务监听地址。平台必须监听 `0.0.0.0`，不能只监听 `127.0.0.1`。

## 5. 日常操作

进入总览查看服务状态；进入现场监控启动摄像头；在 CVAT 标注页保存关键帧和任务进度；管理者在训练页选择人工真值数据并启动真实训练；训练完成后下载 Jetson/服务器部署包。

关闭浏览器不会停止 DGX 上的训练或 CVAT 解码任务。重新登录后可按任务号查看状态。

## 6. 故障处理

- EXE 无法启动：检查解压是否完整、运行库和文件权限，并查看同目录日志。
- 网页能开但摄像头不能用：摄像头接在 DGX 上时由 DGX 采集，Windows 浏览器不直接占用 USB 相机。
- 页面卡顿：优先使用有线网络或稳定 5 GHz，关闭浏览器中其他高码率视频页。
- 只需看三路实时检测：使用 Windows 启动器的“打开 DGX 三路原生监控”，避免完整网页的其他模块请求和渲染开销。
- 无法训练：训练需要管理者权限、可用 CUDA GPU、真实数据 YAML 和已审核标签。
- 下载包不完整：重新下载并核对 SHA-256，不要使用部分下载文件。

## 7. 卸载与数据保留

删除 Windows 客户端目录只删除本地启动器和副本，不会删除 DGX 的数据库、CVAT 项目或模型。需要删除服务器数据时必须由开发者先备份并按变更流程执行。
