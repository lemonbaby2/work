# CVAT 自动缓存、轨迹分段、网盘同步与流程优先任务

更新日期：2026-08-21

## 1. 当前优先级

当前阶段只验收工艺流程和操作动作，不把板内器件型号、极性或细粒度器件正确性作为放行依据。

| 岗位 | 当前必须核对 | 当前不作为主要目标 |
| --- | --- | --- |
| 测试 | 步骤顺序、手势、电脑显示的测试内容是否一致、测试完成状态 | 板内器件型号 |
| 烧录 | 插电顺序、烧录内容与状态、拔线和完成确认 | 单个器件外观 |
| 组装 | 装配内容、标签信息、步骤顺序、手法模式 | 板内器件级精度 |
| 打螺丝 | 螺丝是否存在、点位、是否执行紧固、步骤顺序 | 未接入时虚构扭矩合格 |

扭矩控制器和 MES 回执没有真实接通时，最终状态继续保持 `HOLD`。

## 2. 标注保存与恢复

- 人工框和跟踪框写入 `runtime/sop_annotations.sqlite3`，数据库启用 WAL、`synchronous=FULL`。
- 标注页处于打开状态时，每 60 秒自动创建恢复点，不再只弹提醒。
- 恢复点同时包含当前帧、播放时间、未提交草稿框、SQLite 原子备份和源视频缓存状态。
- 数据库最近备份位于 `runtime/backups/sop_annotations_latest.sqlite3`。
- 源视频优先以硬链接缓存到 `runtime/annotation_video_cache`，不会每分钟重复复制整段大视频。
- 每个视频最多保留 120 个草稿恢复点；页面“恢复自动缓存”按钮可恢复最近一次位置和草稿。

## 3. 轨迹修正与播放

- 自动跟踪仍使用视频画面、稀疏光流和模板匹配，生成结果必须人工复核。
- 播放器通过 `requestVideoFrameCallback` 按视频帧刷新框；稀疏轨迹帧之间使用相邻框线性插值，所以位置和大小在连续播放时同步变化。
- 每条轨迹可以输入起始帧和结束帧后点击“删除此段”；区间外框保留。
- “删除整轨”仍可删除整条轨迹。两种删除都会留下删除人、区间、原因和时间审计记录。
- 跟踪偏离时应缩短区间，在目标转向、遮挡、速度突变处增加人工关键帧，不应依赖一段超长自动轨迹。

## 4. CVAT 中文封装边界

本机实际运行 CVAT `2.73.1`。SOP 页面已提供中文入口：项目、任务、作业、云存储、自动标注模型、Webhook、组织、邀请和 API。

官方 CVAT 负责矩形、多边形、Mask、关键帧插值、自动标注、质量控制、共识和多格式导入导出。本平台补充工位流程模板、每分钟恢复点、轨迹分段删除、SOP/MES/扭矩门禁和标注成片回传。

CVAT 2.73.1 本身没有完整官方中文语言包。当前交付是中文业务导航和工作流封装，官方作业页仍保留原生界面；不能把少量字符串替换描述成完整汉化。

## 5. 每日网盘数据流

网页提供三个动作：

1. 从百度网盘加载新增视频。
2. 从 Google Drive 来源文件夹加载新增视频。
3. 生成带已保存框的标注成片，并回传到 Google Drive 输出文件夹。

拉取完成后，视频会进入 `runtime/cloud_inbox`，自动登记到网页视频目录；页面刷新目录后即可选择。标注成片和同名审计 JSON 输出到 `runtime/annotation_exports`。

Google Drive 必须用 OAuth/rclone，不支持把 Google 账号密码写进代码。配置步骤：

```bash
rclone config
# 分别建立 gdrive-sop-source 和 gdrive-sop-output，根目录绑定对应文件夹 ID
set -a
. config/cloud_sync.env
set +a
./启动SOP平台_DGX.sh
```

参考变量见 `config/cloud_sync.example.env`。百度网盘使用已登录的受控同步客户端，并通过 `SOP_BAIDU_SYNC_COMMAND` 接入。网页永远不接收或保存网盘密码。

## 6. 验收顺序

1. 用测试、烧录、组装、紧固各一段视频确认岗位模板。
2. 人工标两个关键帧，连续播放检查框的位置和大小是否随帧变化。
3. 删除轨迹中一小段，确认前后区间仍存在，导出中不含删除段。
4. 等待 60 秒后刷新页面，通过“恢复自动缓存”恢复播放位置和草稿。
5. 完成 Google OAuth 和百度同步器授权后，分别拉取一段新增视频。
6. 生成标注成片，人工打开检查，再上传 Google Drive 输出目录。
7. 最后才进入器件级标签、冻结真值集、训练和量产精度验收。
