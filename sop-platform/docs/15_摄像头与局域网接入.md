# 摄像头与局域网接入

平台启动后监听 `0.0.0.0:8096`。当前采集主机在同一 WiFi 下的地址为
`http://192.168.1.129:8096`，浏览器访问“现场监控”即可调用后端统一输出的
MJPEG 画面，不需要在 USB 摄像头中安装程序。

## 当前自动发现

- Insta360 Link 2C：`/dev/video0`
- USB Composite Camera：`/dev/video2`
- USB Webcam：`/dev/video5`

`/dev/video1`、`/dev/video3`、`/dev/video6` 是 metadata 节点，不是重复的画面。
`/dev/ttyACM0` 是串口控制/身份通道，串口本身不能传输实时视频。

## RTSP / HTTP 网络相机

将网络相机写入 `config/network_cameras.json`，重启平台后会和 USB 相机一起出现在
摄像头墙。示例：

```json
[
  {"name": "工位4俯视", "url": "rtsp://camera-user:camera-password@192.168.1.50:554/stream1"}
]
```

也可在启动前设置环境变量，多路地址用分号分隔：

```bash
export SOP_NETWORK_CAMERA_URLS='rtsp://192.168.1.50/stream1;http://192.168.1.51/mjpeg'
```

生产环境应给网络相机做 DHCP 地址保留，账号密码放在仅部署主机可读的环境文件中，
不要提交到 GitHub。相机 VLAN、主机防火墙和浏览器客户端必须允许访问 TCP 8096。
