# 新增两视频与前沿SOP架构说明

## 一、给老板的一句话

本项目要建设的是“公司自己能维护的装配SOP智能决策平台”：相机看现场，平台判断做到哪一步，错序或漏装就提醒并留证；只有视觉顺序、拧紧扭矩和MES回执都满足时才能放行。新增岗位时，工艺人员可上传标准视频、修改步骤、复核标注、发起训练和灰度下发。

## 二、本次具体改进

### 1. 两段新视频完整处理

- 视频四：1,620帧，54.00秒，横屏1280×720；
- 视频五：6,536帧，217.87秒，竖屏544×960；
- 两段合计8,156帧、271.87秒、12个SOP步骤；
- 输出统一为1620×720 H.264：左侧完整检测画面，右侧SOP步骤、进度、告警和HOLD原因；
- 竖屏视频采用等比例留黑，不做拉伸；网页顶部工具栏不覆盖视频。

### 2. 大零件框更准

大零件不再只依赖普通矩形检测框，而是先得到实例分割掩膜，再计算掩膜紧边框。随后增加：

1. 不同类别独立阈值；
2. 最小/最大面积与长宽比限制；
3. 肤色比例排除，避免把手臂当成饰板；
4. 跨帧平滑，降低边框跳动；
5. 二次精修重绘，原视频不被修改。

### 3. 小目标识别更细

每个画面切成4个相互重叠的窗口，相当于把螺钉头、卡扣、插头和紧固孔放大后再识别；重叠区域通过NMS合并。新增12类候选共544张抽帧图，标签状态全部为 `pending_human_review`。

小目标候选只是“请标注员重点看这里”，不是螺钉真实数量。量产前应结合更近的相机、局部相机或更高分辨率传感器，不能只靠算法弥补像素不足。

## 三、为什么采用分层算法

| 层级 | 推荐算法 | 作用 | 是否直接放行 |
|---|---|---|---|
| 离线预标注 | YOLOE-26S + SAHI切片 | 快速发现新零件和小目标候选 | 否 |
| 掩膜传播 | SAM 2 / Grounded-SAM-2 | 减少视频逐帧人工画框工作量 | 否 |
| 在线量产 | 人工真值训练的YOLO26/YOLOv8闭集模型 | 稳定识别已定义零件、工具和孔位 | 只提供视觉证据 |
| 动作识别 | MMAction2 / VideoMAE等时序模型 | 区分拿取、放置、压合、紧固等动作 | 否 |
| 业务决策 | 连续帧去抖 + SOP有限状态机 | 判断顺序、超时、跳步和返工 | 参与确定性规则 |
| 最终放行 | 视觉 + PSet/扭矩/角度 + MES回执 | 缺任何关键证据一律HOLD | 是 |

开放词汇模型适合“快速找候选”，闭集模型适合“稳定量产”。大模型可以解释原因和提出建议，但不能绕过确定性放行门。

## 四、公开行业思路的参考方式

本方案只参考公开资料中的架构原则，不声称获得或复制特斯拉、华为的内部SOP、私有代码或工艺数据。

- 特斯拉公开制造页面强调持续迭代、自动化与人工精细操作相互配合，以及制造精度控制。本项目对应为：先做样板工位、持续回收误报漏报、机器人/工具数据与视觉联合判定。参考：https://www.tesla.com/manufacturing
- 华为公开AI质检方案强调行为合规、缺陷/定位/测量、低代码可视化编排、边云协同迭代。本项目对应为：网页SOP编排、人工复核队列、边缘推理、中心模型版本管理。参考：https://e.huawei.com/cn/industries/manufacturing/production-and-supply/ai-quality-inspection
- NVIDIA DeepStream支持多路视频源与批处理，适合现场一台工控机接多相机。参考：https://docs.nvidia.com/metropolis/deepstream/dev-guide/text/DS_ref_app_deepstream.html
- Ultralytics YOLOE用于开放词汇检测/分割；YOLO26强调端到端部署和小目标相关改进。参考：https://docs.ultralytics.com/models/yoloe 和 https://docs.ultralytics.com/models/yolo26
- SAHI通过切片推理提升小目标可见度。参考：https://docs.ultralytics.com/guides/sahi-tiled-inference
- SAM 2可做图像/视频分割与传播，Grounded-SAM-2把文本提示检测与视频分割结合。参考：https://ai.meta.com/research/sam2/ 和 https://github.com/IDEA-Research/Grounded-SAM-2
- MMAction2提供动作识别、时序定位和时空检测工具箱。参考：https://github.com/open-mmlab/mmaction2

## 五、建议的生产架构

```text
固定工业相机/局部小目标相机
        ↓
边缘工控机：解码 → 闭集检测 → 跟踪去抖 → SOP状态机 → 声光/屏幕反馈
        ↓                         ↓
关键帧/短视频/模型版本          电动工具PSet、扭矩、角度
        └──────────┬──────────────┘
                   ↓
             MES接口与最终放行门
                   ↓
        事件审计、返工闭环、难例回收
                   ↓
       中心训练服务器：复核、训练、验收、灰度下发、回滚
```

一台RTX 4060工控机先按3路1080P、每路10–15FPS验收；完成TensorRT/DeepStream压力测试后再讨论4路。实际容量受分辨率、模型大小、切片数量、录像编码、并发规则和可接受延迟影响，不能只凭显卡型号承诺。

## 六、训练结果如何理解

YOLO26N学生模型训练12轮，验证集81张、352个自动候选实例：

- 精确率：74.51%；
- 召回率：16.77%；
- mAP@0.50：17.13%；
- mAP@0.50:0.95：11.33%。

这些数值只说明学生模型对YOLOE自动预标注的拟合程度。召回率偏低，说明它会漏掉较多教师候选；因此当前PT/ONNX仅作为训练管线与部署格式验证，不得直接量产下发。正确下一步是人工复核、补充难例、重新划分冻结测试集后再训练。

## 七、人工标注验收清单

1. 每个框贴紧目标边缘，避免把手、背景或邻近零件一起框入。
2. 小于8像素、无法判断类别的候选标为“忽略”，不要强行标螺钉。
3. 螺钉头、螺栓头、紧固孔、塑料卡扣不能相互混用。
4. 遮挡超过70%的目标按质量部门规范决定是否标注，并保持全数据集一致。
5. 同一产品SN或同一连续视频段不能同时出现在训练集和测试集。
6. 至少双人复核关键漏装/错序样本，质量人员签字后冻结测试集。

## 八、上线后持续工作

- 每周查看误报、漏报、HOLD和人工放行原因；
- 每月或达到难例数量门槛后发起候选模型训练；
- 新模型先离线回放，再单工位灰度，满足业务指标后扩大范围；
- 模型、SOP配方、相机标定和MES接口均版本化，任何变更可追溯、可回滚；
- 相机移动、治具变化、光照改变、车型变更时必须触发重新验收。
