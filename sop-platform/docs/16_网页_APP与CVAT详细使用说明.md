# SOP 网页、Windows APP 与 CVAT 详细使用说明

版本：`soplzp0820`
更新日期：2026-08-20

## 1. 地址与用途

| 服务 | DGX 本机 | 同一局域网客户端 |
| --- | --- | --- |
| SOP 网页 | `http://127.0.0.1:8096` | `http://192.168.1.129:8096` |
| 官方 CVAT | `http://localhost:8081` | `http://192.168.1.129:8081` |

2.4 GHz 和 5 GHz 无需不同版本。只要手机、平板、电脑与 DGX 位于同一路由器的同一 LAN/VLAN，且路由器关闭 AP/客户端隔离，两种频段都通过上表同一个局域网地址访问。

## 2. DGX 启动网页

进入项目目录后执行：

```bash
SOP_HOST=0.0.0.0 SOP_PORT=8096 micromamba run -n sop python server.py
```

`0.0.0.0` 表示同时接受本机和局域网请求。不要把服务直接映射到公网互联网；工业视频、模型和标注数据应只在厂内网络传输。

启动后先检查：

```bash
curl http://127.0.0.1:8096/api/health
```

返回 `status: ok` 后再打开浏览器。Ubuntu 防火墙启用时，需要由管理员在厂内网范围放行 TCP `8096` 和 `8081`。路由器若把 2.4G 与 5G 放在不同 VLAN，还要配置两网段互通；仅同名 Wi-Fi 不代表一定互通。

## 3. Windows APP 启动

1. 打开 `D:\soplzp0820_20260820\app`。
2. 双击 `SOP平台.exe`。
3. 等待命令窗口显示后端启动完成，浏览器会自动打开网页。
4. APP 所在 Windows 主机只运行本机页面时访问 `http://127.0.0.1:8096`。
5. 需要其他设备访问时，确认 APP 后端监听 `0.0.0.0`，并在 Windows Defender 防火墙仅对“专用网络”放行 TCP `8096`。
6. 关闭 APP 前先完成“保存本次进度”，确认顶部状态为“所有修改已保存”。

## 4. 页面导航

- `01 实时总览`：查看产线状态、事件和当前步骤。
- `02 视频复盘`：选择完整视频，点击 S01-S04 跳到对应时段并显示 ROI。
- `03 SOP 编排`：调整步骤名称、顺序和时间，保存为新版本。
- `04 智能决策`：查看当前帧目标、规则链和 HOLD 原因。
- `05 CVAT 标注`：人工修正框、关键帧插值、保存、复核及导出。
- `06 模型训练`：选择候选模型、查看统一指标和图表；未人工验收模型保持 HOLD。
- `07 质量验收`：查看 QA 报告和人工复核边界。
- `08 设备接入`：检查 USB、RTSP/HTTP 局域网摄像头和串口设备。

## 5. S01-S04 视频交互

在“视频复盘”选择 0264 或 0265 后：

1. 点击 `S01 取料候选`，播放器跳到取料区间起点并高亮物料 ROI。
2. 点击 `S02 元器件对位候选`，跳到对位区间并显示对应时间范围。
3. 点击 `S03 插装/按压候选`，跳到插装区间并高亮 PCB 操作区。
4. 点击 `S04 完成复检候选`，跳到复检区间。
5. 每项都显示开始时间、结束时间和持续时长。当前区间为自动候选，工序边界须人工确认。

## 6. 05 CVAT 标注标准流程

### 6.1 创建或打开 CVAT 任务

1. 查看“CVAT 在线”状态。
2. 输入任务名称，选择 PCB 数据集。
3. 点击“创建 CVAT 任务”。
4. 创建结果会出现在“CVAT 任务记录”，点击“打开任务”进入官方 CVAT。
5. 已部署服务地址为 `http://192.168.1.129:8081`。本机内部 API 使用 `http://localhost:8081`。

DGX 上的接口令牌保存在权限为 `600` 的 `runtime/cvat_token`，后端重启时会自动读取；该目录被 Git 忽略。不要把令牌内容写入 Markdown、截图、日志或公开仓库。

CVAT 页面使用本机已有的 `admin` 或 `annotator1` 至 `annotator5` 账号登录。若管理员忘记密码，应在 DGX 终端交互式重置，密码不会出现在命令历史中：

```bash
sg docker -c 'docker exec -it cvat_server python3 manage.py changepassword admin'
```

### 6.2 在 SOP 页面画框并保存

1. 选择 0264 或 0265 视频。
2. 用上一帧/下一帧按钮定位关键帧，无需逐帧画框。
3. 选择区域：左/中/右 PCB 区、电容物料区、电感物料区、混合物料区、人员操作区或 NG 复核区。
4. 选择标签，包括 PCB、电容、电感、电阻、连接器、手部和各操作行为。
5. 在视频上按住鼠标拖出 YOLO 矩形框。
6. 点击工具栏中的“保存这个框”。后端立即写入 SQLite，保存证据截图并同步刷新框数量。
7. 完成一批框后点击“保存本次进度”。后端创建新的保存轮次、执行 WAL checkpoint，并生成数据库备份。
8. 工具栏下方显示“第 N 次保存”、帧号、框数量、涉及区域和保存时间。
9. 页面每 60 秒提醒一次；存在未保存框时，关闭或刷新页面也会警告。

顶部的“保存当前区域/保存全部进度”和画框工具栏里的“保存这个框/保存本次进度”调用同一组后端接口，任意一组都能真正落库。

### 6.3 关键帧插值

1. 在起始关键帧保存一个框。
2. 在下方已保存标注中点击“载入框”。
3. 跳到后续关键帧，重画目标的新位置。
4. 点击“插值到当前关键帧”。
5. 检查生成的中间框，遮挡、方向变化、工序切换和 NG 位置必须补关键帧。

固定目标建议每 15-30 帧设关键帧；手、工具和运动目标建议每 3-5 帧设关键帧。

### 6.4 审核与导出

1. 在“当前帧候选与已保存标注”中载入框。
2. 正确框点击“确认”；错误框点击“驳回”或退回修正。
3. 使用“下载坐标 CSV/JSON”导出坐标。
4. 使用“一键下载完整 ZIP”导出人工确认数据、审核记录、截图、代理视频和数据库快照。
5. 所有 NG、稀有类别和工序边界必须人工复核。

## 7. 官方 CVAT 内保存

CVAT 与 SOP 页是两个独立的标注客户端：

1. 在 CVAT 作业页使用官方“保存”按钮或 `Ctrl+S` 保存 CVAT 标注。
2. 返回 SOP 页面后点击“刷新任务”查看任务入口。
3. SOP 页创建的框必须点击“保存这个框”；CVAT 的保存动作不会自动替代 SOP SQLite 的保存按钮。
4. 完成阶段性复核后仍应在 SOP 页点击“保存本次进度”，形成可审计轮次和数据库备份。

## 8. 摄像头使用

1. 在“设备接入”点击刷新，确认 USB 摄像头 `/dev/video*`、稳定 by-id 路径或 RTSP/HTTP 地址。
2. 在实时页面选择摄像头，点击“启动实时检测”。
3. 系统使用容量为 1 的最新帧邮箱，推理忙时丢弃过期帧，避免延迟不断累积。
4. 点击“保存截图”留证；点击“开始录制/停止录制”保存检测视频。
5. 浏览器卡顿时先降低摄像头分辨率或 FPS，并检查 Wi-Fi 信号、客户端隔离和局域网丢包。

## 9. 5 轮快速训练与模型选择

当前快速训练预算为 5 轮，用于验证数据链路和生成客户候选，不代表模型已经优秀或可量产。

1. 在模型训练页选择数据集、算法和 GPU。
2. 启动 5 轮训练并等待验证、测试和图表生成。
3. 比较 Precision、Recall、mAP50、mAP50-95 与推理延迟。
4. 指标是与自动教师候选的一致性；未锁定人工真值测试集前不能称为生产精度。
5. 客户选择模型后仍保持 `HOLD`，人工验收通过后才能发布。

- 标注证据图：`/home/xjai/Desktop/sop xjai/标注图片`
- 摄像头证据：`/home/xjai/Desktop/sop xjai/摄像头证据`
- 人工复核数据集：`datasets/PCB插装0264_YOLOE_ROI增强_待人工复核` 和 `datasets/PCB插装0265_YOLOE_ROI增强_待人工复核`

网页异常时先刷新 `/api/health`，再查看 `/api/annotations/database`。数据库返回 `integrity: ok`、`journal_mode: WAL` 后再继续标注。不要在服务运行时直接覆盖 SQLite 主文件；应通过“保存本次进度”生成备份后再复制。

## 11. 人工验收底线

- 自动预标注、动作区间和 ROI 都是候选。
- PCB、电容、电感及混合物料区域必须分别检查漏框、错类和重复框。
- 训练、验证、测试按完整视频或产品 SN 划分，禁止相邻帧泄漏。
- 未完成人工冻结真值集验收前，模型、网页决策和实时检测一律保持 `HOLD`。
