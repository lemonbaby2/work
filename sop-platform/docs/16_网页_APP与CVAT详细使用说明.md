# SOP 网页、Windows APP 与 CVAT 详细使用说明

版本：`soplzp0821-annotation-v2`
更新日期：2026-08-21

## 1. 地址与用途

| 服务 | DGX 本机 | 同一局域网客户端 |
| --- | --- | --- |
| SOP 网页 | `http://127.0.0.1:8096` | `http://192.168.1.129:8096` |
| 官方 CVAT | `http://localhost:8081` | `http://192.168.1.129:8081` |

2.4 GHz 和 5 GHz 无需不同版本。只要手机、平板、电脑与 DGX 位于同一路由器的同一 LAN/VLAN，且路由器关闭 AP/客户端隔离，两种频段都通过上表同一个局域网地址访问。

## 2. DGX 启动网页

进入项目目录后执行：

```bash
SOP_HOST=0.0.0.0 SOP_PORT=8096 micromamba run -n sop python server.py
```

`0.0.0.0` 表示同时接受本机和局域网请求。不要把服务直接映射到公网互联网；工业视频、模型和标注数据应只在厂内网络传输。

启动后先检查：

```bash
curl http://127.0.0.1:8096/api/health
```

返回 `status: ok` 后再打开浏览器。Ubuntu 防火墙启用时，需要由管理员在厂内网范围放行 TCP `8096` 和 `8081`。路由器若把 2.4G 与 5G 放在不同 VLAN，还要配置两网段互通；仅同名 Wi-Fi 不代表一定互通。

## 3. Windows APP 启动

1. 打开 `D:\soplzp0820_20260820\app`。
2. 双击 `SOP平台.exe`。
3. 等待命令窗口显示后端启动完成，浏览器会自动打开网页。
4. APP 所在 Windows 主机只运行本机页面时访问 `http://127.0.0.1:8096`。
5. 需要其他设备访问时，确认 APP 后端监听 `0.0.0.0`，并在 Windows Defender 防火墙仅对“专用网络”放行 TCP `8096`。
6. 关闭 APP 前先完成“保存本次进度”，确认顶部状态为“所有修改已保存”。

## 4. 页面导航

- `01 老板总览`：查看产线状态、事件、处理边界和当前步骤。
- `02 现场监控`：选择完整视频，点击 S01-S04 跳到对应时段并显示 ROI；也可查看三路实时摄像头。
- `03 现场证据处置`：查看当前帧目标、缺失证据、责任动作和 HOLD 原因。
- `04 SOP 编排`：调整步骤名称、顺序和时间，保存为新版本。
- `05 CVAT 标注`：人工修正框、关键帧插值、保存、复核及导出。
- `06 训练与部署`：选择候选模型、查看统一指标和图表；未人工验收模型保持 HOLD。
- `07 MES 对接`：配置工单、SN、工艺结果和放行回执接口。
- `08 标注与模型对比`：查看 QA 报告、算法差异和人工复核边界。

## 5. S01-S04 视频交互

在“现场监控”选择任一视频后，页面会显示该视频的 S01-S04 候选区间；当前共包含原有 7 段和宁波 8 月 19/20 日新增 16 段：

1. 点击 `S01 取料候选`，播放器跳到取料区间起点并高亮物料 ROI。
2. 点击 `S02 元器件对位候选`，跳到对位区间并显示对应时间范围。
3. 点击 `S03 插装/按压候选`，跳到插装区间并高亮 PCB 操作区。
4. 点击 `S04 完成复检候选`，跳到复检区间。
5. 每项都显示开始时间、结束时间和持续时长。当前区间为自动候选，工序边界须人工确认。

## 6. 05 CVAT 标注标准流程

### 6.1 创建或打开 CVAT 任务

1. 查看“CVAT 在线”状态。
2. 输入任务名称，选择 PCB 数据集。
3. 在视频复盘或 05 标注页先选中目标视频，再点击“创建并上传整段视频”。
4. 创建结果会出现在“CVAT 任务记录”，点击“打开任务”进入官方 CVAT。
5. 已部署服务地址为 `http://192.168.1.129:8081`。本机内部 API 使用 `http://localhost:8081`。

DGX 上的接口令牌保存在权限为 `600` 的 `runtime/cvat_token`，后端重启时会自动读取；该目录被 Git 忽略。不要把令牌内容写入 Markdown、截图、日志或公开仓库。

CVAT 页面使用本机已有的 `admin` 或 `annotator1` 至 `annotator5` 账号登录。若管理员忘记密码，应在 DGX 终端交互式重置，密码不会出现在命令历史中：

```bash
sg docker -c 'docker exec -it cvat_server python3 manage.py changepassword admin'
```

### 6.2 在 SOP 页面画框并保存

1. 先在“固定工位标注口径”确认工位、质量判定目标和两种物料；管理者可修改并保存，标注员按页面显示的统一口径执行。
2. 固定工位只标注能支撑本工位质量判定的目标：`PCB板`、`操作人员手部`、`物料框`、`手持插件`和`插件位置`。不需要把画面里每个电容、电阻都标出来。
3. “二极管插件”和“其他插件”只有在选错会影响工艺判定时才区分；如果两者对本工位判定无差别，取消勾选，统一标为`手持插件`。
4. 从全部视频标注池选择目标视频；播放器载入完整 H.264 代理视频，不是单张图片。
5. 点击画面下方的播放/暂停按钮可正常播放视频；使用左右箭头逐帧查看，“跳帧数”配合 `-跳帧/+跳帧` 可跨越多帧，也可在“帧”输入框直接输入帧号。
6. 选择区域和标签，在视频上按住鼠标拖出 YOLO 矩形框。
7. 点击“保存这个框”立即写入 SQLite；完成一批后点击“保存本次进度”创建保存轮次和数据库备份。
8. 工具栏下方显示保存轮次、帧号、框数量、涉及区域和保存时间；标注页打开时每 60 秒自动缓存 SQLite 快照、当前播放位置、草稿框和源视频恢复副本。

顶部的“保存当前区域/保存全部进度”和画框工具栏里的“保存这个框/保存本次进度”调用同一组后端接口，任意一组都能真正落库。

### 6.3 自动轨迹跟踪与关键帧校正

1. 在起始帧画好框，点击“设为起始关键帧”。起始帧状态会明确显示帧号、标签和轨迹 ID。
2. 轨迹 ID 可留空由系统生成，也可填写易懂的编号，例如 `diode-left-01`。它用于把同一目标在多帧中的框归为一条轨迹，不是数量输入框。
3. 使用播放、跳帧或帧号输入到后续帧。页面会立即复制起始框作为参考，当前帧晚于起始帧后，“自动跟踪到当前帧”会直接解锁，不必先移动结束框。
4. 根据复核密度选择“轨迹框间隔”，点击“自动跟踪到当前帧”。系统会读取原视频，使用 MIL 外观跟踪、稀疏光流和局部模板匹配跟随目标，再保存起始框和中间候选框。
5. 如果结束帧自动结果已知或目标发生明显变形，可先拖动框体改变位置，或拖动八个白色控制点改变大小。按钮会显示“自动跟踪并按结束框校正”，系统会把当前框作为人工结束关键帧修正整段轨迹。
6. “当前视频轨迹”会显示轨迹 ID、标签、区域、起止帧、框数和已生成帧号；点击“查看起始帧”可跳回，填写起止帧后可删除问题片段，也可点击“删除整轨”删除全部。
7. 连续播放使用浏览器逐视频帧回调刷新框；稀疏轨迹帧之间按相邻框插值，框的位置和大小不会停留在暂停帧。
8. 逐段检查生成框。点击当前帧列表的“载入框”后，可以拖动框体、使用八个控制点缩放并再次保存，也可以删除单帧框、轨迹片段或整条轨迹。目标转向、速度突变、遮挡和工序切换仍建议缩短区间并增加人工关键帧。

固定目标建议每 15-30 帧设关键帧；手、工具和运动目标建议每 3-5 帧设关键帧。

### 6.4 审核与导出

1. 在“当前帧候选与已保存标注”中载入框。
2. 正确框点击“确认”；不确定但要保留记录时点击“驳回”。AI 检测预标注、小目标候选和人工框均可点击“删除”，不再只能驳回。
3. 删除任一框或整条轨迹后，该标注会立即从画面、复核队列和训练导出中移除，数据库保留删除人、来源、时间和原因的审计记录。
4. 使用“下载坐标 CSV/JSON”或“一键下载完整 ZIP”导出人工确认数据、审核记录、截图、代理视频和数据库快照。
5. 所有 NG、稀有类别和工序边界必须人工复核。

## 7. 官方 CVAT 内保存

CVAT 与 SOP 页是两个独立的标注客户端：

1. 在 CVAT 作业页使用官方“保存”按钮或 `Ctrl+S` 保存 CVAT 标注。
2. 返回 SOP 页面后点击“刷新任务”查看任务入口。
3. SOP 页创建的框必须点击“保存这个框”；CVAT 的保存动作不会自动替代 SOP SQLite 的保存按钮。
4. 完成阶段性复核后仍应在 SOP 页点击“保存本次进度”，形成可审计轮次和数据库备份。

## 8. 摄像头使用

1. 在“设备接入”点击刷新，确认 USB 摄像头 `/dev/video*`、稳定 by-id 路径或 RTSP/HTTP 地址。
2. 在实时页面选择摄像头，点击“启动实时检测”。
3. 系统使用容量为 1 的最新帧邮箱；显示目标 15 FPS、推理目标 5 FPS，最近检测框复用到显示帧。
4. 三路 GPU 调度最多公平等待 25 ms。超过上限时该路直接显示最新帧并复用最近框，不让旧帧形成长队。
5. 点击“保存截图”留证；点击“开始录制/停止录制”保存检测视频。
6. 浏览器卡顿时先降低摄像头分辨率或 FPS，并检查 Wi-Fi 信号、客户端隔离和局域网丢包。

## 9. 5 轮快速训练与模型选择

当前快速训练预算为 5 轮，用于验证数据链路和生成客户候选，不代表模型已经优秀或可量产。

1. 在模型训练页选择数据集、算法和 GPU。
2. 启动 5 轮训练并等待验证、测试和图表生成。
3. 比较 Precision、Recall、mAP50、mAP50-95 与推理延迟。
4. 指标是与自动教师候选的一致性；未锁定人工真值测试集前不能称为生产精度。
5. 客户选择模型后仍保持 `HOLD`，人工验收通过后才能发布。

## 11. 人工验收底线

- 自动预标注、动作区间和 ROI 都是候选。
- PCB、电容、电感及混合物料区域必须分别检查漏框、错类和重复框。
- 训练、验证、测试按完整视频或产品 SN 划分，禁止相邻帧泄漏。
- 未完成人工冻结真值集验收前，模型、网页决策和实时检测一律保持 `HOLD`。
