# 三视频多物体预标注数据集

本目录由三段真实仪表板装配视频自动抽帧并预标注生成。

## 当前状态

`全部待人工复核`。这些标签不能直接作为正式训练真值。

## 目录

- `images/pending_review`：每15帧抽取一张，共469张。
- `labels/pending_review`：对应YOLO格式标签，共469份。
- `manifest.jsonl`：每张图片的来源视频、帧号、时间、标注来源和复核状态。
- `classes.json`：7类目标定义。
- `dataset_stats.json`：数据统计。

## 标注来源

- `business_roi_seed`：工艺区域初始框，需要固定相机后重新校准；
- `YOLOv8_pseudo_label`：YOLOv8自动预标注的人员手部和工具；
- `YOLOv8切片小目标候选器`：紧固点候选，误报风险较高，必须逐框复核。

## 复核要求

1. 删除误报框；
2. 修正框的边界；
3. 补齐漏标零件和真实螺钉；
4. 将“紧固点候选”改成正式的螺钉/螺栓类别；
5. 由第二人抽检；
6. 复核通过后再按工单或视频会话分组进入train/val/test。
