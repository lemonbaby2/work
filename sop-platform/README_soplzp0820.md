# SOP 平台 soplzp0820

本目录是 2026-08-20 的源码分支交付，包含网页标注、SQLite WAL 持久化、关键帧插值、
YOLOE PCB 预标注、YOLO26N 50 轮训练、USB/RTSP 摄像头接入和 DGX/局域网部署代码。

## 本次 PCB 数据

- 源视频：`DJI_20260819151908_0265_D.MP4`，659.27 秒，原始 4K/59.94 FPS。
- 关键帧：1,182 张训练帧；完整任务合计 2,879 张。
- 候选标注：25,531 个，全部为待人工复核的伪标签。
- 切分：0265 完整视频仅训练；工位 4 的 1/2 视频验证；3/6 视频测试。
- 训练：`scripts/train_pcb_0265_50_epochs.py` 固定要求不少于 50 轮。

原视频、抽帧图片、SQLite 数据库和模型权重属于内部运行数据，没有提交到公开 GitHub。
它们保存在 DGX 项目目录，并将数据库/清单同步到 Windows 主机的
`C:\Users\lzp\sop_dgx_data`。

## 运行

```bash
micromamba run -n sop python server.py
```

本机访问 `http://127.0.0.1:8096`，同一局域网访问 `http://<采集主机IP>:8096`。
详细相机接入见 `docs/15_摄像头与局域网接入.md`。

所有自动框、动作区间、NG、稀有类别和工序边界都必须人工复核；教师伪标签指标不能
作为量产精度或自动放行依据。
