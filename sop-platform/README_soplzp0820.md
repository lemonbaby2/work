# SOP 平台 soplzp0820

本目录是 2026-08-20 的源码分支交付，包含网页关键帧标注、按区域保存、关键帧插值、
60 秒保存提醒、SQLite WAL 持久化、YOLOE PCB 预标注、YOLO26N 5 轮快速训练、
三模型客户选择与统一精度图，以及 USB/RTSP 摄像头与 DGX 局域网接入。

## PCB 数据与训练

- `DJI_20260819145537_0264_D.MP4`：945.57 秒，1,595 张目标视频训练关键帧。
- `DJI_20260819151908_0265_D.MP4`：659.27 秒，1,182 张目标视频训练关键帧。
- 自动候选合计 51,823 个，全部待人工复核。
- 训练、验证、测试按完整源视频隔离，避免相邻帧泄漏。
- 提供 0264 单视频、0265 单视频和 0264+0265 联合三个 5 轮快速候选模型；正式量产仍须人工真值复训与验收。

## Windows 应用

两台交付主机的目标目录均为：

```text
D:\soplzp0820_20260820\app
```

双击 `SOP平台.exe` 后端会自动启动。程序优先使用已配置的 GPU Python 环境，否则回退到
随包 Python 3.12 嵌入式运行时以提供网页、标注、SQLite 和报告功能。

## DGX 运行

```bash
micromamba run -n sop python server.py
```

默认本机访问 `http://127.0.0.1:8096`，同一局域网访问
`http://<采集主机IP>:8096`。详细相机接入见 `docs/15_摄像头与局域网接入.md`。
网页、Windows APP、CVAT 创建任务、两级保存按钮和保存轮次的完整操作见
`docs/16_网页_APP与CVAT详细使用说明.md`。

原始 4K 视频、抽帧图片、SQLite 数据库和模型权重作为内部数据资产交付到 Windows D 盘，
不提交到公开 GitHub。所有自动框、动作区间、NG、稀有类别和工序边界都必须人工复核；
教师伪标签指标不能作为量产精度或自动放行依据。
