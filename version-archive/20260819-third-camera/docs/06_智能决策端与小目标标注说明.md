# 智能决策端与小目标标注说明

## 一、这次升级了什么

平台已经从“播放一段有框的视频”升级为三段真实视频的统一SOP决策端：

- 三段视频、7,007帧、18个SOP步骤统一管理；
- 视频二和视频三使用YOLOv8-World加BoT-SORT跨帧跟踪；
- 每个检测结果不仅显示框，还进入“目标—区域—顺序—紧固质量—MES—放行”决策链；
- 决策端显示风险分、证据强度、判断理由和下一步建议；
- 人工可以把结果标记为误报、需要返工或人工确认，全部写入审计记录；
- 缺少扭矩或MES回执时，无论视觉结果多高，最终状态始终是HOLD。

这种设计参考了当前主流视频分析能力：Ultralytics官方支持在连续视频帧中使用BoT-SORT、ByteTrack等保持目标ID，并指出移动相机适合使用带相机运动补偿的BoT-SORT；NVIDIA DeepStream的事件录像方案强调只保存重要事件前后的证据片段，降低存储压力。

- Ultralytics跟踪说明：https://docs.ultralytics.com/modes/track/
- Ultralytics YOLO-World说明：https://docs.ultralytics.com/models/yolo-world/
- NVIDIA DeepStream事件录像：https://docs.nvidia.com/metropolis/deepstream/9.1/text/DS_Smart_video.html

## 二、为什么不能直接承诺螺钉已经100%识别

三段视频拍的是整个仪表板总成，分辨率为1280×720。很多螺钉头在画面中只有几到十几个像素，同时存在手部遮挡、运动模糊、反光和手持相机移动。即使模型给出高置信度，也可能把圆形卡扣、标签、孔位或金属反光误认为螺钉。

因此本次实现采用两级方法：

1. 第一层识别大目标：仪表板、风道/模块、线束/接插件区域、人员手部、电动工具；
2. 第二层把画面切成四个重叠窗口放大，再运行YOLOv8紧固件候选模型，输出红色“紧固点候选”。

第二层结果是为了减少人工漏标，不是正式真值。所有红框均带 `pending` 状态，必须由人员在标注页确认、调整或删除。

## 四、正式螺钉检测应怎么继续

1. 改用固定工业相机，在每个真实孔位保证螺钉头至少约20–30像素；
2. 单独采集“有螺钉、漏螺钉、浮钉、歪钉、错钉、遮挡、反光”近景；
3. 人工复核本次候选框，删除误报并补齐漏框；
4. 按工单/产品SN划分训练、验证和冻结测试集，禁止随机拆分相邻帧；
5. 训练宁波专用YOLOv8s小目标模型，并增加切片训练/推理；
6. 用每个孔位的漏检率验收，而不是只看总体mAP；
7. 最终紧固合格还必须同时核对电动工具PSet、扭矩和角度。

## 五、智能决策的权限边界

- YOLO模型：提供目标框、类别和置信度；
- 跟踪器：判断同一目标是否连续出现；
- SOP状态机：判断顺序、等待时间和必需条件；
- 智能建议：解释风险并建议工人或班组长下一步操作；
- 确定性放行门：只有视觉、扭矩、MES三方证据齐全才允许PASS；
- 人工复核：处理误报、返工和特殊放行，并留下人员和时间记录。

智能建议不能直接越权修改SOP、删除审计记录或绕过放行门。
