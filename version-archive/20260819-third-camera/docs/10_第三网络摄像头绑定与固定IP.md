# 第三网络摄像头绑定说明

## 已核实身份

截图中的第三摄像头已经绑定到平台配置：

```text
名称：镭威视电池智链摄像机
IP：192.168.1.135
MAC：c4:3c:b0:be:40:e8
网关：192.168.1.1
DNS：192.168.1.1
子网掩码：255.255.255.0
协议：RTSP
平台编号：camera 2
```

当前 Ubuntu 主机可发现该设备，TCP 554 端口曾成功开放，RTSP 服务标识为 `Hopeway RealServer/V1.0`。常见的海康/大华路径没有返回有效 SDP，因此平台不会伪造 RTSP 路径。

## MAC 与 IP 怎么固定

推荐两者同时使用，但职责不同：

- IP 是访问地址，网页和视频服务通过 `192.168.1.135` 访问。
- MAC 是设备身份，绑定时用来确认不会把另一台摄像头误接入。
- 最稳妥的固定方式是在路由器 `192.168.1.1` 中建立 DHCP 静态租约：MAC `c4:3c:b0:be:40:e8` 固定分配 IP `192.168.1.135`。
- 如果设备 App 已经设置为手工静态 IP，也要确保路由器 DHCP 地址池不包含 `.135`，避免 IP 冲突。

## 页面操作

进入“现场监控”页，在“网络摄像头 3 绑定”区域：

1. 保持 IP、MAC、网关、DNS和掩码为现场参数。
2. 从摄像头 App 的“分享/局域网/RTSP”页面复制完整流地址，填入 RTSP 地址。
3. 点击“测试 RTSP”，测试返回视频流信息后再点击“保存绑定”。
4. 相机选择器选择“网络摄像头3 · 192.168.1.135”，点击“启动实时检测”。

当前默认地址 `rtsp://192.168.1.135:554/` 只是占位地址，不能代表实际视频流；必须填写厂家实际路径和必要的用户名/密码。
