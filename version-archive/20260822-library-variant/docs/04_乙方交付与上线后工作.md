# 乙方交付成果与上线后工作

## 乙方应交付

1. SOP分析平台前端和后端源代码；
2. 标注任务、数据集版本和抽检功能；
3. YOLOv8训练、验证、导出和版本管理流程；
4. 实时视频推理、SOP状态机和告警程序；
5. 模型及其类别、阈值、适用工位说明；
6. MES接口、离线补传、事件幂等和审计日志；
7. 相机、补光、工控机和网络部署图；
8. 样板工位SOP配方、零件区域和验收记录；
9. 安装包、启动脚本、运维手册、备份和回滚说明；
10. 面向工艺、质量、IT和操作员的培训及签到材料。

## 甲方需要配合

- 工艺工程师确认正确步骤、孔位和异常处置；
- 质量工程师提供正常/异常判定和验收门槛；
- 生产部门安排样板工位、操作人员和试运行窗口；
- IT/MES团队提供网络、服务器、账号和接口测试环境；
- 工具供应商开放拧紧控制器原始报文。

## 部署后还要持续做

### 每日

- 检查相机、补光、画面偏移和工位在线状态；
- 复核高风险告警，异常帧进入待标注池。

### 每周

- 统计漏装拦截、错序拦截、误报、人工放行和MES补传；
- 对新物料、新手套、新光照或新班次样本补标。

### 每月或变更后

- 重新评估模型和SOP版本；
- 产品、治具、相机位置或工艺变化后必须重新验证；
- 演练模型回滚、断网补传和磁盘清理。

## 正式验收证据

- 按工单/产品SN隔离的冻结测试集；
- 正常、漏装、错序、装错、遮挡等场景数量；
- 漏装拦截率、错序拦截率、误报率和P95响应时间；
- 8小时以上连续运行报告；
- 断网、重启、MES重复报文和模型回滚测试；
- 工艺、质量、生产、IT四方签字。
