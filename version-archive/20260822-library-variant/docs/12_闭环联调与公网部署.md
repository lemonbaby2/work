# 数据闭环、轨迹标注与现场联调

## 已落地的闭环

`视频索引 -> 受控缓存播放 -> FFmpeg 抽帧/事件切片 -> OpenCV 清晰度与相似帧检查 -> YOLO/RT-DETR/Grounding DINO/YOLOE+SAM2 候选 -> 人工框选与轨迹编辑 -> CVAT/Label Studio -> FiftyOne QA -> DVC 版本 -> 训练/验证 -> 单工位灰度 -> 低置信度/误报/漏报回流`。

平台的 `/api/video-library` 会扫描：

- `/home/xjai/Desktop/sop xjai/视频数据/宁波SoP项目/8月20号`
- `/home/xjai/Desktop/sop xjai/视频数据/宁波SoP项目/8月21`

导入只登记白名单路径并提供 Range 播放，不复制超大原片。抽帧、质量检查和去重应把结果写入 `runtime/video_quality.jsonl`，训练前再冻结数据集并记录 SHA256。

## 轨迹标注

标注页先在起始帧框选目标，点击“设为起始框”，跳到后续帧点击“生成轨迹到当前帧”或“自动追踪到末尾”。前端立即显示快速预测，后端 `/api/annotations/track` 再用逐帧检测和 IoU 连续匹配修正。起始帧永远保持人工锚点；任何当前帧拖框会写成可编辑轨迹点。轨迹保存到 `runtime/annotation_tracks.jsonl`，包含 `track_id`、`annotator_name`、`remarks` 和方法说明。

这是标注辅助轨迹，不等同于 SAM2 真值。正式训练前必须由标注员和质量员逐帧抽检，确认后才能导出。

## 身份留痕

标注页提供 `标注员1` 至 `标注员5` 以及 `标注员12345` 的身份建议，可输入真实姓名。人工框、审核、轨迹和视频导入均记录操作人、时间、备注与来源；质量员的确认/驳回写入 `runtime/annotation_reviews.jsonl`。

## USB Type-C 工控机联调

Type-C 只代表物理连接，可能枚举为 UVC 摄像头、USB 串口、USB 网卡或仅供电。平台的“设备身份、串口和主机网络”页会读取 `/dev/video*`、`/dev/ttyACM*`、`/dev/ttyUSB*`、udev 属性和 `ip -j addr`。摄像头没有独立 IP/MAC，网络摄像头才有。

优先使用 Station Agent 反向出站链路：工控机主动向 DGX/平台建立 HTTPS/WebSocket 连接，上传心跳、视频片段和 MES 事件；不要为了远程维护直接暴露 SSH。若现场必须 SSH，使用厂内 VPN/跳板机、密钥登录、最小权限账号、固定源 IP 和审计，不使用密码或公网端口转发。

## 公网与 CVAT

公网隧道只暴露反向代理的 HTTPS 端口，Label Studio/CVAT/DGX 推理服务留在内网，设置 SSO、访问令牌、上传大小限制和审计日志。CVAT 导出后先转 Datumaro/YOLO 格式，再由 FiftyOne 做重复帧、空标注、框越界和类别统计；DVC 只提交元数据和校验值，大视频放对象存储或 NAS。
