# 三段视频右侧 SOP 步骤看板说明

## 一、改进目的

三段演示视频均在原 1280×720 检测画面右侧增加 340×720 的独立 SOP 看板，最终视频为 1620×720。看板不覆盖相机画面，因此人员、工具、零件区域和螺钉候选框仍然完整可见。

## 二、看板内容

- 顶部显示视频名称、当前时间、总时长和整体进度。
- 中部固定列出全部六个 SOP 步骤。
- 绿色“完”表示步骤已完成。
- 橙色“当”表示当前正在执行的步骤。
- 灰色数字表示后续待执行步骤。
- 底部显示生产放行状态。本次没有真实扭矩控制器和 MES 回执，因此保持 `HOLD`，不把视觉通过冒充生产放行。

## 三、三个输出文件

1. `web/media/仪表板SOP_YOLOv8逐帧识别演示_小目标增强版_右侧SOP步骤面板版.mp4`
2. `web/media/仪表板SOP_视频二_d66_YOLOv8逐帧智能分析_小目标增强版_右侧SOP步骤面板版.mp4`
3. `web/media/仪表板SOP_视频三_e344_YOLOv8逐帧智能分析_小目标增强版_右侧SOP步骤面板版.mp4`

网页会优先播放上述三个新版视频。下拉切换视频后，右侧步骤看板和检测画面同步切换。

## 四、在 VSCode 中重新生成

打开项目文件夹后按 `F5`，选择“重做：三视频右侧SOP步骤面板”。运行环境固定为：

`D:\Anaconda\envs\dl\python.exe`

也可以在已激活的 `dl` 环境中运行：

```powershell
python scripts/render_right_sop_panel.py
```

脚本读取 `web/data/videos.json` 中每段视频的六步定义，逐帧计算当前步骤，生成 H.264、30 FPS、支持网页快进拖动的 MP4，并回写 `presentation_video` 字段。
