# 现场部署与容量建议

## 推荐拓扑

固定相机与补光采集画面，经工业交换机进入工控机。工控机在本地完成YOLOv8推理和SOP判断，直接驱动显示屏/声光报警；同一时间把结果、关键帧和短视频发送到服务器，再由接口服务与MES交换工单和质量结果。

本地判断不能依赖外网。即使服务器或MES暂时不可用，现场告警仍应有效，结果进入离线队列，恢复网络后按事件编号幂等补传。

## 单工位建议清单

| 类别 | 建议 | 说明 |
|---|---|---|
| 工业相机 | 3台，200万像素以上，全局快门优先 | 俯视整体+侧视细节+补位视角 |
| 镜头 | 按视野和工作距离选型 | 现场实测后确定焦距 |
| 补光 | 2组无频闪条形/面光 | 避免手部阴影和金属反光 |
| 工控机 | Intel i7/Ryzen 7，32GB内存，1TB SSD，RTX 4060或更高 | 首期按3路相机验收 |
| 网络 | 千兆工业交换机，工位与服务器时钟同步 | 便于视频和MES事件追溯 |
| 显示告警 | 15–21英寸显示器、蜂鸣器/三色灯 | 绿/黄/红明确反馈 |
| 工具接口 | 电动工具控制器以OPC UA、TCP、MQTT或厂商协议接入 | 必须获得PSet、扭矩、角度、OK/NOK |
| UPS | 约1kVA | 防止异常断电损坏本地队列 |

品牌、镜头焦距、安装支架和最终数量必须现场勘察后冻结，本表用于预算和方案比较，不用于直接采购。

## 容量口径

- 基准验收：一台RTX 4060工控机带3路1080P视频，每路10–15帧/秒；
- 可选扩展：TensorRT优化后进行4路压力测试；
- 录像存储与AI推理分开计算，连续保存完整视频会显著增加磁盘和网络压力；
- 建议量产默认保存告警前后短视频和关键帧，完整录像按公司合规要求设置保留周期；
- 验收时至少连续运行8小时，检查GPU温度、显存、帧延迟、丢帧、MES补传和磁盘增长。

## 相机安装验收

1. 治具、相机和补光有机械防松标记；
2. 正常操作时手部遮挡不能同时覆盖所有关键区域；
3. 不同班次的工作服、手套和环境光都在训练数据中；
4. 相机移动后平台强制重新标定，旧模型不可直接放行；
5. 每日开班用标准样件做快速点检。
